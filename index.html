📥 Import Data Cepat (Bulk Insert)

Tempelkan (paste) data program KPR dalam format JSON di bawah ini untuk menambahkan atau memperbarui banyak program sekaligus, tanpa perlu mengisi form satu per satu. Program dengan nama yang sama persis pada bank yang sama akan ditimpa (update), bukan digandakan.

Keterangan Field

• nama_bank — nama bank (wajib, alias: bank)
• nama_program — nama program KPR (wajib)
• min_tenor — tenor minimum program berlaku, dalam tahun 1–30 (wajib)
• max_tenor — tenor maksimum program berlaku (opsional; isi jika program berlaku utk rentang tenor, mis. "All Tenor 1–4 Thn")
• akad — "konvensional" / "syariah" / "syariah-efektif" (opsional, default "konvensional")
• skema_bunga — daftar periode bunga berurutan (wajib, minimal 1 tahap, alias: skema):
  – suku_bunga — persen bunga/margin, wajib diisi kecuali tahap ini "floating" (alias: bunga, margin)
  – masa_fixed — durasi tahap ini dalam tahun
  – tipe — "fixed" (default jika tidak ditulis) atau "floating"
• floating_rate — asumsi persen untuk semua tahap floating pada program ini (opsional, default 11%)
• plafon_min / plafon_max — syarat plafon dalam Rupiah (opsional)
💡 Untuk program dengan rentang tenor (ada max_tenor), total durasi masa_fixed sebaiknya mencakup sampai tahun ke-max_tenor supaya rate berlaku penuh di seluruh rentang.

⚠ Format JSON tidak valid.
